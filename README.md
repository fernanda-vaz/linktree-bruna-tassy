# Linktree - Bruna Tassy

Este projeto é uma página de links personalizada desenvolvida utilizando **HTML**, **CSS** e **JavaScript**, criada para organizar e centralizar os principais conteúdos e redes sociais de um profissional ou marca pessoal. O design é moderno, minimalista e responsivo, refletindo uma experiência de usuário intuitiva e eficiente.

## Tecnologias e Abordagens

- **HTML**: Estruturação semântica e organizada do conteúdo.  
- **CSS**: Estilização personalizada, com foco em responsividade e design minimalista.  
- **JavaScript**: Adição de interatividade, como animações e manipulação de eventos.  
- **Responsividade**: Utilização de CSS Flexbox para garantir uma exibição consistente em dispositivos móveis, tablets e desktops.  
- **Deploy na Vercel**: Plataforma utilizada para publicação e hospedagem estável da aplicação.  

## Funcionalidades

- **Centralização de Links**: Apresentação de múltiplos links organizados de forma visualmente atraente.  
- **Botões Personalizados**: Estilização única para cada botão, adaptada às necessidades do usuário.  
- **SEO Básico**: Uso de HTML semântico para melhorar a indexação em motores de busca.  
- **Responsividade Total**: Experiência consistente em diferentes dispositivos, com foco em acessibilidade.

## Como Executar Localmente

1. Clone o repositório:  
   ```bash  
   git clone https://github.com/fernanda-vaz/linktree-bruna-tassy.git  
   ```  

2. Navegue até o diretório do projeto:  
   ```bash  
   cd linktree-bruna-tassy  
   ```  

3. Abra o arquivo `index.html` em seu navegador.
